## 已实现

- 项目文档体系：`README.md`、`AGENTS.md`、`docs/PRD.md`、`docs/ARCHITECTURE.md`、`docs/PROGRESS.md`、`docs/P0-BASELINE.md`。
- `web/` 工程骨架：Vite 8 + React 19 + TypeScript + react-router 8 + vite-plugin-pwa。
- 路由与外壳：`/`、`/review`、`/records`、`/settings`；底部三栏导航，右上角设置入口。
- 三个主页面与设置页为占位内容，无业务逻辑。
- PWA：manifest、图标、Service Worker 生成（`dist/sw.js`）。
- Dexie 数据库 `EnglishLearnDB` v1，10 张表：`courses`、`courseModules`、`answers`、`grades`、`knowledge`、`reviews`、`mistakes`、`studyDays`、`aiUsage`、`settings`。
- 启动时打开数据库并写入默认设置（幂等，不覆盖已有数据）；失败时显示错误页而非白屏。
- 领域类型定义：`src/types/domain.ts`（课程、模块、题目、作答、批改、知识点、复习、错题、学习日、AI 用量）。
- Vitest 测试：`src/db/db.test.ts`、`src/data/sampleCourses.test.ts`、`src/repositories/courseRepository.test.ts`。
- 2 节示例课程（`src/data/sampleCourses.ts`），每节 4 模块：单词 5 个（含音标、例句与译文）、语法 2 段讲解 + 4 道选择题、阅读 1 篇（含译文）+ 1 选择 + 1 翻译题、巩固 2 题。标记 `source: 'sample'`，首页与课程页显示“示例”徽标。
- 首页读取当前课程（未完成优先，否则编号最小未开始），显示目标、四模块状态与“开始/继续学习”。
- 课程页 `/course/:id`：课程信息与模块清单；点击开始会把课程标记为进行中并写入开始日期。
- 示例课程与知识点只在缺失时写入，重复启动不重复插入。
