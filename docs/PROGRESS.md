## 已实现

- 项目文档体系：`README.md`、`AGENTS.md`、`docs/PRD.md`、`docs/ARCHITECTURE.md`、`docs/PROGRESS.md`、`docs/P0-BASELINE.md`。
- `web/` 工程骨架：Vite 8 + React 19 + TypeScript + react-router 8 + vite-plugin-pwa。
- 路由与外壳：`/`、`/review`、`/records`、`/settings`；底部三栏导航，右上角设置入口。
- 三个主页面与设置页为占位内容，无业务逻辑。
- PWA：manifest、图标、Service Worker 生成（`dist/sw.js`）。
- Dexie 数据库 `EnglishLearnDB` v1，10 张表：`courses`、`courseModules`、`answers`、`grades`、`knowledge`、`reviews`、`mistakes`、`studyDays`、`aiUsage`、`settings`。
- 启动时打开数据库并写入默认设置（幂等，不覆盖已有数据）；失败时显示错误页而非白屏。
- 领域类型定义：`src/types/domain.ts`（课程、模块、题目、作答、批改、知识点、复习、错题、学习日、AI 用量）。
- Vitest 测试：`src/db/db.test.ts`、`src/data/sampleCourses.test.ts`、`src/repositories/courseRepository.test.ts`。
- 2 节示例课程（`src/data/sampleCourses.ts`），每节 4 模块：单词 5 个（含音标、例句与译文）、语法 2 段讲解 + 4 道选择题、阅读 1 篇（含译文）+ 1 选择 + 1 翻译题、巩固 2 题。标记 `source: 'sample'`，首页与课程页显示“示例”徽标。
- 首页读取当前课程（未完成优先，否则编号最小未开始），显示目标、四模块状态与“开始/继续学习”。
- 课程页 `/course/:id`：课程信息与模块清单；点击开始会把课程标记为进行中并写入开始日期。
- 课程内模块页 `/course/:courseId/module/:kind`：顶部返回与“模块 n / 4”，一次只显示一个模块；语法、阅读、复习暂为占位。
- 单词模块：逐个呈现（词形、音标、释义、例句与译文），可前后翻页，末页“完成单词模块”写入模块状态；已完成可重看并显示提示。
- 模块状态持久化：`updateModuleStatus`，首页与课程页进度随之更新。
- 语法与练习模块：可折叠语法讲解、逐题作答、选项即时本地批改并显示解析；未答完不能完成模块。
- 阅读与翻译模块：短文卡片、可展开参考译文、选择 + 翻译输入；译文输入 400ms 防抖保存，失焦、切换模块、页面隐藏与组件销毁时立即保存。
- 巩固复习模块：复用同一套答题与批改组件。
- 通用答题组件 `QuizModule` + `QuestionCard`：四种模块共用作答、批改、恢复、翻题与完成逻辑。
- 课程完成：四个模块全部完成后课程标记 `completed` 并写入完成日期，首页自动切到下一课。
- 错题记录：答错即写入错题（id 与作答一致），同一题后来答对会清除；记录页展示题干、你的答案、正确答案与解析。
- 学习时长：模块页按可见时间累计，30 秒心跳，隐藏与离开时落库；同日汇总为一行。
- 学习天数：同一天只记 1 天；满足“累计 ≥5 分钟”或“完成 ≥1 模块”才算有效学习日。
- 记录页：按日期列出已开始／已完成课程（模块进度、客观题正确率），并可进入课程回看。
- 备份与恢复：导出 JSON（应用标识 + 版本 + 全部表）；导入先完整校验（字段、主键唯一、引用完整），校验通过后才在单个事务内替换全部表；导入失败不动现有数据；确认恢复前自动下载当前数据备份。
- AI 代理（`web/server/`）：`/api/course/generate`、`/api/grade`、`/api/tutor` 三个接口；默认 `mock` 供应商，可选 OpenAI 兼容接口；CORS 白名单、64KB 请求上限、超时、限流、并发上限、幂等缓存、每日请求/token 预算、结构化日志（不含密钥与作答内容）。
- AI 服务端校验：课程结构归一化并重写全部 id；批改只接受 `correct / partial / uncertain`；请求字段逐项限长。
- 前端 AI：单飞请求合并、40 秒超时、错误码转中文、结构校验后才落库；模拟与真实来源在课程上标记 `generatedBy`。
- 课程生成入口在设置页；生成结果写入确定性 id `ai-<课号>`，重复保存不会产生第二份。
- 开放题批改：阅读翻译题可“请老师批改”，写入 `source: 'ai'` 的批改与说明；`uncertain` 显示“暂无法判断”，允许修改后重新批改。
- 课程内“问老师”：按课程上下文提问，显示回答与连接错误。
- 作答存储：确定性 id `课程:模块:题号`，同一题重复保存为覆盖；答案与批改在同一事务写入。
- 客观题判分：`utils/grading.ts`，选择题按选项 id 比对；填空题做全半角、大小写、空格、弯引号与句末标点归一化。
- 示例课程与知识点只在缺失时写入，重复启动不重复插入。

## 未验证

- 手机与 iPad 真机。
- PWA 安装与离线行为（需 HTTPS，P5 验收）。
- 文本自动保存的四个触发点只做了整体验证（离开再进入能恢复），没有逐个单独验证防抖、失焦、页面隐藏各自的写入时机。
- 真实跨天：只验证了“课程带旧开始日期仍会被继续”的逻辑与单元测试，没有真的等到第二天或改系统时间验证日期归属。
- 备份恢复的界面导入未在浏览器实际选文件验证；校验与恢复语义由单元测试覆盖。
- 学习时长依赖页面可见时间与心跳，长时间挂机、休眠与系统时间跳变的准确性未验证。
- 真实 AI 调用完全未执行：模型参数、结构化输出开关、计费口径都没有按官方文档核对，也没有人工抽查真实课程。
- `mock` 课程内容不是教学材料，只用于验证流程。
- 代理预算账本只存在内存，进程重启后当天计数清零；持久用量在本地 `aiUsage` 表。
- 真实模型返回超长或越界内容时只做结构拒绝，未统计拒绝率。
- PWA 离线时发起 AI 请求的行为未实现（P5 待处理）。
- 数据库版本升级路径（当前只有 v1，无历史版本可测）。
- 示例课程的教学内容只做过结构与语法规则自校，没有外部教师审校。
