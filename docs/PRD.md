# PRD：英语学习 PWA

状态：P0 基线，待 P1 实现。所有功能描述均为**目标**，不代表已可用。

## 1. 目标

单人、日常可持续的英语学习工具。核心是“今天学一节，随时能接着学，学过的东西按规则回来复习”。

不追求：题库规模、社交、竞技、多端同步、完整考试模拟。

## 2. 使用者

- 一名学习者，固定使用自己的设备（Windows 浏览器、手机、iPad 中至少一台为主）。
- 无人监督，因此“打开就能继续”“不用手动保存”“进度可信”比功能多更重要。

## 3. 首版范围

### 3.1 主页面

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/` | 今日 | 当前课程（编号、主题、学习目标）、四模块进度、主按钮“开始学习／继续学习”、今日学习时长 |
| `/review` | 复习 | 到期复习项列表，每项写明进入复习的原因；错题重做入口 |
| `/records` | 记录 | 按日期倒序的课程记录（完成模块、客观题正确率、时长），可进入课程回看 |
| `/settings` | 设置（右上角） | 数据管理（备份／恢复／导入预览）、AI 用量与预算、版本与离线状态 |

首页只呈现当前课程，不做课程列表堆叠。

### 3.2 课程内部

固定四模块，按顺序推进，一次只突出一个模块：

1. 单词（词形、释义、音标、例句）
2. 语法与练习（讲解 + 客观题）
3. 阅读与翻译（短文 + 翻译／理解题）
4. 巩固复习（本节知识点混合回顾）

交互要求：顶部显示课程进度与退出入口，底部为“下一模块”。退出后进度保留，回到首页按钮变为“继续学习”。

### 3.3 学习记录

- 客观题自动批改并展示解析。
- 开放题在 P1 显示“待批改”，P2 起由 AI 批改并标注“暂无法判断”情形。
- 错题进入错题表，可按课程回看。
- 学习时长按本地日期累计；同日重复打开不增加学习天数。

### 3.4 数据

- 本地 IndexedDB 为唯一数据源。
- JSON 导出／导入；导入前校验，导入失败不得破坏现有数据。
- 示例课程与真实学习数据必须可区分。

## 4. 分阶段优先级

| 阶段 | 用户可见结果 |
| --- | --- |
| P1 | 示例课程可学、可答、可保存、可恢复 |
| P2 | AI 生成课程、批改开放题、课程内提问 |
| P3 | 历史进度导入并确认，从可靠位置继续 |
| P4 | 到期复习与按薄弱点调整下一课 |
| P5 | 可安装、可离线、目标设备验收 |

## 5. 验收标准（首版整体）

- 无 API Key 时可完成一节示例课程。
- 输入答案后刷新或关闭重开，内容仍在原处。
- 跨天后能继续原课程，历史日期与时长归属正确。
- 同一天反复打开不重复增加学习天数。
- 损坏的备份文件导入失败，旧数据完整保留。
- 320–1280px 宽度下无横向溢出，输入框可用。
- 断网时可打开已缓存课程并保存作答（P5）。
- 未验证的设备与功能在文档中明确列出。

## 6. 暂不开发

- 听力、口语评测、写作专项。
- 完整模拟考试与分数报告。
- 复杂统计图表（趋势、雷达图）。
- 账户体系、跨设备自动同步、多人共享。
- 推送通知、社交分享。
